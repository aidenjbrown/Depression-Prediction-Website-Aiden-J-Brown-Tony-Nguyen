# Depression Prediction Website

Project website presenting the methods, visualizations, and results from a collaborative NHANES depression score prediction analysis.

This project was completed for Intermediate Data Science at Vassar College by Aiden Brown and Tony Nguyen.

## Project Summary

This website presents an exploratory data science project using NHANES 2017–2018 survey data to evaluate whether demographic, income, sleep, work, weight, and health-related variables could predict depression score.

The project includes exploratory data analysis, regression models, classification modeling, SHAP-based model interpretation, and discussion of the limits of prediction from the available survey variables.

## Note

This project is for exploratory analysis and research practice only. It is not intended for diagnosis, clinical screening, or individual decision-making.
